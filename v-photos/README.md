# Vehicle Photographs

This directory is reserved for photographs of the actual Qatar FE vehicle and its mechanical/electrical assemblies.

## Recommended documentation set

| File name | Required view |
|---|---|
| `vehicle_overview.jpg` | Full vehicle, three-quarter view |
| `vehicle_top_view.jpg` | Top view showing component layout |
| `vehicle_front_view.jpg` | Front geometry and steering |
| `vehicle_rear_view.jpg` | Rear drive assembly |
| `steering_linkage.jpg` | Close-up of steering mechanism |
| `sensor_mounting.jpg` | Gyro and ultrasonic mounting |
| `pixy2_mounting.jpg` | Camera mounting and viewing direction |
| `printed_parts_installed.jpg` | Custom printed parts installed on the vehicle |

## Photographing standard

- Use even lighting and a plain background.
- Keep the camera approximately perpendicular for dimension-reference views.
- Include a ruler only when a dimension is being documented.
- Do not infer dimensions from perspective photographs.
- Capture close-ups of joints, cable routing, and mounting interfaces.
