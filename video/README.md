# Video Documentation

This directory is reserved for original Qatar FE development, testing, and competition videos.

## Recommended video register

| File name | Content | Evidence purpose |
|---|---|---|
| `open_challenge_run.mp4` | Complete Open Challenge run | Navigation and lap sequence |
| `obstacle_detection.mp4` | Red and green pillar detection | Vision classification |
| `obstacle_avoidance.mp4` | Pillar passing manoeuvres | Clearance and lane transition |
| `parking_sequence.mp4` | Final parking manoeuvre | Parking execution |
| `steering_test.mp4` | Low-speed steering sweep | Steering direction and travel |
| `sensor_test.mp4` | Ultrasonic and camera observations | Sensor integration |

## Recording protocol

For each recording, document:
- date and test identifier;
- software version;
- hardware configuration;
- test objective;
- test conditions;
- observed result;
- related CSV log, if available.

## Video index

No demonstration video is listed until an original recording is supplied and reviewed. Keep raw recordings unchanged and publish compressed copies only when necessary.
